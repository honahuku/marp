# 私がスライドを作るときに意識すること

ページごとに、伝えたい内容に合う見せ方を選ぶ。結論、図、コード、比較、詳しい説明では、それぞれ読みやすい形に組み立てる。

## 見た目に理由を持たせる

本文は白地に黒い文字を基本にし、アクセント色は強調したい箇所に絞る。色や形を足すときは、登壇者や話題、イベントとのつながりを考える。内容と関係のない飾りを繰り返すと、何を伝えたいのかがぼやける。

背景色や角丸の枠、カード状の囲みを、すべてのページに一律で使わない。表紙や章扉では、写真や図形、色を使って個性を出してもよい。本文では内容を読み取る邪魔にならないことを優先する。

## 内容に合わせてページの形を選ぶ

短い結論は大きく見せる。構成図は広く置く。コードには説明を添え、比較する内容は並べて違いを示す。背景や制約を伝えるページでは、必要な情報を順序立てて載せる。すべてを同じレイアウトにせず、話の流れに合わせて変化を付ける。

一枚に情報を一つだけ載せる、という決まりにはしない。情報量は話す時間と説明の順序に合わせる。細かい説明が必要なときは、文字を小さく詰め込む前に、ページを分けたり図に置き換えたりできないか考える。

## 投影でも読める文字・図・コードにする

見出し、本文、注記の大きさに差を付け、ページの中で何が大切かを伝える。投影したときに読める大きさか、PDFにした状態でも確かめる。

構成図では、ノード名や矢印、通信方向を読み取れるようにする。色を複数使うなら、役割や状態などの意味に対応させる。コードは説明に必要な部分に絞り、注目箇所を言葉で補う。スクリーンショットや写真は、細部を見せたいなら十分な大きさで配置する。

## テンプレートの使い方

テンプレートには、短い主張、構成図、コードと説明、比較、詳しい説明に使えるページを用意する。毎回すべての型を使う必要はない。話の流れに合うものを選び、必要ならレイアウトを調整する。
