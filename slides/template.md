# 書き込み処理の要点

# 遅延が増える条件

書き込みが特定のノードに集中すると、そのノードの処理待ちが長くなる。複製先への転送や応答待ちも、書き込み時間に加わる。

利用者から見える遅延は、処理時間だけでは決まらない。どこで待ちが発生するかを図や計測値で示し、原因と影響を結び付けて説明する。
